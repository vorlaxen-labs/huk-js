# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 2.x     | Yes       |

## Reporting a vulnerability

Please report security issues via [GitHub Security Advisories](https://github.com/vorlaxen-labs/huk-js/security/advisories/new) or open a private contact through [vorlaxen-labs/huk-js issues](https://github.com/vorlaxen-labs/huk-js/issues) with the subject **Security**.

Do not disclose critical issues in public issues before a fix is available.
